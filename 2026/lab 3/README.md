#  Library Management System (Node.js)

Консольное приложение для управления библиотекой книг.


##  Доступные команды

| Команда               | Пример                                                | Описание                                                                      |
| --------------------- | ----------------------------------------------------- | ----------------------------------------------------------------------------- |
| Добавить книгу        | `node app.js addBook "Война и мир" "Толстой" 12345 3` | Добавляет книгу в библиотеку (или увеличивает количество, если ISBN уже есть) |
| Добавить пользователя | `node app.js addUser "Иванов" "Иван" 1`               | Регистрирует нового пользователя                                              |
| Выдать книгу          | `node app.js issue 12345 1`                           | Выдаёт книгу пользователю (уменьшается количество доступных экземпляров)      |
| Список книг           | `node app.js listBooks`                               | Показывает список всех книг с количеством                                     |
| Вернуть книгу         | `node app.js return 12345 1`                          | Возвращает книгу в библиотеку                                                 |
